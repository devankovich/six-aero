This folder is a flattened static snapshot of the Six.Aero brochure site (Home, Services, About Us, Contact), taken from a wget mirror of six.aero and rewritten so it can be uploaded as a webroot with index.html at the root. The six-item menu is unchanged: Home (/), Services (/services1), Sling Aircraft (https://slingaircraft.my, new tab), About Us (/about-us), Contact (/contact), and Register (Google Form, new tab). Stub pages our-fleet and aircraft-listings are omitted. Images, theme CSS, and Basekit JS are loaded from the same public Cloudfront URLs the live site already uses (d2f0ora2gkri0g, d282ykz6vx01th, d3b4n3yyoc8n59); parent-directory ../cloudfront.net links from wget were converted to https:// so the site does not depend on the snapshot folder layout. The contact form markup is left as-is (it has no action and originally relied on Basekit JS); a mailto:Hello@six.aero line sits under the form as a fallback. Copy is original; this is not a redesign. Upload this directory as the site webroot. Do not publish from this README; it is documentation only.
